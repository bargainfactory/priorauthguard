# PriorAuthGuard — Frontend (placeholder)

The Next.js 15 app (App Router, TypeScript, Tailwind, shadcn/ui) lands in
**Phase 3**, including:

- ROI Dashboard (light + dark).
- `PrivacyFHEPanel.tsx` (Shield/CheckCircle iconography, real-time FHE metrics,
  trust-building progress states).
- Intake wizard wired to `/v1/intake`.
- Live voice console wired to the WS surface.

The shared design system uses an emerald accent on a near-white / near-black
canvas with backdrop-blur cards. Both modes ship from day one.
